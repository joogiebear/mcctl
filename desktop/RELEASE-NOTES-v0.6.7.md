mcctl is open

The source is public now: **github.com/joogiebear/mcctl** — code, issues, release
history and installers, all in one place. The full release history has moved
there too.

This update's job is mostly to carry you across: apps installed as v0.6.6 or
earlier check the old feed for updates, and installing v0.6.7 points your app
at the new home, so every update after this one arrives from the main
repository. Nothing else about your servers, settings or backups changes.

If you have ever wanted to read how something works, report a bug next to the
code that has it, or build mcctl yourself — the door is open.
